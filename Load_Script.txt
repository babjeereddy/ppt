Grade, MinMarks, MaxMarks

RESIDENT LOAD
A resident load reads a table already loaded into memory.
Students:
LOAD *
FROM [lib://Data/Students.txt]
(txt, utf8, embedded labels, delimiter is ',', msq);

StudentSummary:
LOAD
    Class,
    Count(StudentID) AS StudentCount,
    Avg(Age) AS AverageAge
RESIDENT Students
GROUP BY Class;


Preceding LOAD
A preceding load places one LOAD statement above another.
Students:
LOAD
    StudentID,
    Trim(StudentName) AS StudentName,
    Age,
    If(Age >= 16, 'Senior', 'Junior') AS AgeGroup;
LOAD
    StudentID,
    StudentName,
    Age
FROM [lib://Data/Students.txt]
(txt, utf8, embedded labels, delimiter is ',', msq);


The lower load reads the CSV. The upper load transforms its result.

Qlik Sense automatically concatenates tables when they have the same number of fields with matching field names.

NOCONCATENATE prevents Qlik Sense from automatically combining the new table with another table that has the same structure.


SalesCalculated:
NOCONCATENATE
LOAD
    *,
    Quantity * UnitPrice AS GrossSales
RESIDENT Sales;

ApplyMap() looks up the region target without joining an entire table into the sales records. The 0 is the fallback value if the region isn't found.

RegionTargetMap:
MAPPING LOAD
    Region,
    MonthlyTarget
FROM [lib://Data/Targets.txt]
(txt, utf8, embedded labels, delimiter is ',', msq);

SalesWithTarget:
LOAD
    *,
    ApplyMap('RegionTargetMap', Region, 0) AS MonthlyTarget
RESIDENT Sales;

What is Incremental Load?
Incremental Load is a technique in Qlik Sense that loads only new or changed records from a Data source instead of reloading the entire Dataset every time.

For example, suppose a sales table contains 10 lakh records. Every day, only 500 new sales records are added.
- Full load: Reloads all 10 lakh records.
- Incremental load: Loads the new 500 records and combines them with previously stored Data.



IF NOT IsNull(QvdCreateTime('lib://Data/Sales.qvd')) THEN

 
    Sales:
    LOAD
        OrderID,
        Customer,
        Amount
    FROM [lib://Data/Sales.qvd] (qvd);

    // Append only new records from the source
    Concatenate (Sales)
    LOAD
        OrderID,
        Customer,
        Amount
    FROM [lib://Data/Sales.txt]
    (txt, utf8, embedded labels, delimiter is ',', msq)
    WHERE NOT Exists(OrderID);

ELSE

    // First reload: load all source records
    Sales:
    LOAD
        OrderID,
        Customer,
        Amount
    FROM [lib://Data/Sales.txt]
    (txt, utf8, embedded labels, delimiter is ',', msq);

ENDIF

// Save the updated Dataset
STORE Sales INTO [lib://Data/Sales.qvd] (qvd);
